# AVM ADAS Probe

把改裝安卓車機（Unisoc UIS7862 / Mali-G52）上的環景鏡頭，做成像特斯拉那樣的**周遭物件 3D 顯示**，全部在原機上跑，不外掛算力。

車輛：BMW 525i E60（4.841 × 1.846 m，軸距 2.888 m）。螢幕 1920×720。

## 功能總覽

純文字版：[docs/功能清單.txt](docs/功能清單.txt)

兩種用法：

- **標準版 App**（這個 repo 的 `app`）：自己接鏡頭，畫面在本 App 的四格／3D 面板裡。
- **合併版**（`engine360` + `merge360/`）：把偵測引擎注入原廠 360 App，直接在原廠 360 畫面上標注。
  改過的原廠 APK 是閉源程式的衍生物，不在這裡發佈，要用 `merge360/build-b.sh` 自己產生（見 [docs/merged-360.md](docs/merged-360.md)）。

### 偵測

| 功能 | 說明 |
|---|---|
| 周遭物件 | 汽車、廂型車、大車、機車、自行車、行人、三角錐（YOLO，GPU 推論）；前方用去畸變的寬角／窄角虛擬鏡頭 |
| 物件追蹤 | 卡爾曼追蹤、速度、行進方向；停在格子裡的車照格子方向畫 |
| 重複合併 | 多顆鏡頭看到同一台車只留一個框（同群組、沿視線方向放寬），重疊只留信心度最高的 |
| 前車距離 | 接地點 + 車寬兩種估法，取較可靠的（前鏡頭裝得低，遠處接地點容易算近） |
| 車道線 | 白／黃／紅線、虛實線、雙白／雙黃線、彎道（二次擬合）；時間平滑，停車時不閃 |
| 路緣 | 左右路面邊界 |
| 停車格 | 垂直／平行／斜角格、有無車、植草磚；被自車擋住的共用線也認得出 |
| 紅綠燈 | 模型 + 高解析燈點偵測（亮、飽和、外圈暗燈箱的小圓點，紅黃綠） |
| 前車燈號 | 前車煞車燈、雙閃、左右方向燈 |

### 輔助與警示

| 功能 | 說明 |
|---|---|
| 碰撞預警 | 離自車太近（依車身外框算淨距）變色、提示音 |
| 前車起步／轉綠燈 | 停等時前車開走、號誌轉綠提醒 |
| 車道偏移 | 速度達門檻（設定可調 30～70 km/h）且沒打燈往線靠近 |
| 壓線行駛 | 車輪壓線超過 2 秒；壓實線顯示「違規」 |
| 變道輔助 | 打燈畫車寬走廊到目標車道；那側有車變紅、實線／雙線打叉；變道過程中跟著目標車道走，到了就收掉 |
| 轉彎輔助 | 方向盤轉過門檻照實際角度；還沒轉時照前方道路彎度預測；掃過範圍（含內輪差）有人車變紅；前方直路改畫變道線 |
| 倒車入庫 | 規劃到最近的空格或使用者點選的格子；倒車時打方向燈自動選那一側的空格 |
| 雙閃找路邊空位 | 慢速打雙閃時記錄右側路邊停放的車與紅線，找夠長的空隙，畫平行停車路線（往前多少公尺停下、再倒車兩段弧入位） |
| 雙閃引導至路肩 | 高速打雙閃：前方急煞只提醒注意後方；否則畫往右切到路肩的引導線 |
| 提示音 | 起步、偏離、來車、危險各有不同聲音；走導航提示聲道並要求暫時插播，沒播音樂也聽得到（聲道可切換） |

| 功能 | 說明 |

| 行車記錄器 | 合成畫面（俯視圖 + 前方 + 標注 + 車速、方向燈、檔位、煞車推估）硬體編碼錄影，循環錄影、撞擊自動鎖定、SRT 字幕；自車用原廠車模圖案 |
| 診斷工具 | 存原始影格、還不支援的畫面自動存檔、煞車訊號探測、匯出原廠車模與設定檔、閃退保護（自己造成的閃退累積兩次自動停用） |

### 已知還做不到

- 煞車訊號：車機與原廠 360 都沒有，只能從車速下降推估。
- 方向盤角度：來源未確認準不準；原廠的動態輔助線（畫面跟著方向盤轉）時標注可能對不上。
- 使用者手動拖動原廠 3D 後，3D 標注先隱藏到切換視角為止。

   │   （側鏡頭 a/b 兩塊、前後中央 c）  │           │

### 座標約定

車身座標原點在車輛footprint 中心的地面點，x 向右、y 向上、z 向前（公尺）。
3D 場景 x = x、z = −z（前方是 −Z）。JSON 角度用度，payload 的 `yaw` 用弧度。
詳見 `docs/v03-spec.md`。

## 使用

### 鏡頭直讀模式（建議）

1. 主畫面選 **鏡頭直讀**，授予相機與定位權限
2. 進畫面後會輪流偵測四個鏡頭，右側 3D 面板即時顯示
3. 離開前景會自動釋放鏡頭；鏡頭被別的 App 占用時會自動重連

> 全景360 目前**先不要移除**，它還負責倒車影像。它的設定裡把「轉向聯動」關掉，才不會打方向燈時跳出來搶鏡頭。

### 截螢幕模式（舊路線）

1. 主畫面選 **模型 / 引擎 / 3D 面板位置**（改完要停止再開始）
2. **① 授予懸浮窗權限** → **② 開始偵測** → 允許螢幕擷取
3. 切到全景360、開**俯視畫面**；螢幕左半會出現黃色虛線框（偵測區）
4. 右側 3D 面板按 **校正**：拖滑桿讓虛線框剛好框住俯視圖；調「橫向寬度」讓實景地面上的車身跟 3D 自車一樣寬
5. 用面板底部切 **俯視 / 3D 跟車 / 繞行**

### 車機訊號探測

主畫面的**訊號探測**頁會認平台、掃廠商與全景360 的廣播字串、監聽 60 秒的系統屬性變動、試綁 CAN/MCU 服務，並可**匯出全景360 的 APK**。
用途是找出方向燈、倒車、方向盤轉角、雷達距離的讀取管道，再寫成 adapter 接到 `VehicleBus.signals`。

## 鏡頭校正

`app/src/main/assets/avm_calib.json` 是魚眼鏡頭幾何（內參、外參、俯視圖範圍）。預設值未校正。

要產生真正的校正檔：

1. 車停好不動，鏡頭直讀畫面按**存原始畫面** → `raw_*.jpg` + json
2. 截螢幕模式 3D 面板按**校正** → **存截圖** → `screen_*.png` + json（含 roi/wm/flip）
3. 跑擬合工具：

```bash
# roi / wm / flip 照著存截圖時一併存下的 json 填
python3 tools/fit_calib.py raw_xxx.jpg screen_xxx.png \
    --roi 0.0,0.0,0.5,1.0 --wm 8.0 \
    -o app/src/main/assets/avm_calib.json --debug-dir /tmp/fit
```

產出的檔案會帶 `"calibrated": true`。合成資料上誤差 < 1 cm；真實資料尚未驗證。

幾何在 Kotlin（`AvmGeometry.kt`）與 Python（`tools/avm_geometry.py`）是逐位元一致的，改動其中一邊要兩邊一起改並跑 `tools/test_fit_calib.py`。

## 模型

`app/src/main/assets/model_*.tflite`。

| 檔案 | 內容 |
|---|---|
| `model_yolo11n_*.tflite` | YOLO11n（COCO 80 類），預設 |
| `model_yolo26s_o365_fp16w_256.tflite` | 車種細分（Objects365）：多了箱型車、三角錐等類別，Mali-G52 估 100–140 ms |

車種依標籤名稱對應到顯示種類（`ObjTypes.kt`），NMS 依車種群組做，避免「car」和「van」互相壓掉。
**重機與機車目前沒有模型分得出來**，需要台灣標註資料訓練或另外接裁切分類器。

重新匯出 COCO 模型：

```bash
pip install ultralytics
python tools/export_model.py --imgsz 320
```

> 第一次匯出若出現 `duplicate registrations for aten.miopen_batch_norm`，是轉換器在同一個行程裡自動安裝造成的，重跑一次即可。

int8 版信心分數會被量化成粗階（多半顯示 50%），偵測結果與 fp32 相同。

## 簽章

每版都用同一把固定金鑰簽（憑證 SHA-256 `fa5736a4…6e92`），新版可直接覆蓋安裝，設定不會被清掉。

金鑰不進版控：`signing/avm-adas-probe.jks` + 專案根目錄的 `keystore.properties`：

```properties
storeFile=signing/avm-adas-probe.jks
storePassword=…
keyAlias=avm
keyPassword=…
```

沒有這兩個檔案時會退回本機 debug key（可以建置，但裝到車機上要先解除安裝舊版）。

## 已知限制

- 俯視圖上的車是被 IPM 拉長的俯視形狀，COCO 模型信心偏低；鏡頭直讀改送正方形裁切後明顯改善，但畫面邊緣嚴重變形的車仍會漏抓，之後要做魚眼去畸變後再偵測。
- 重機與機車分不出來（見上）。
- 3D 面板與偵測共用 Mali-G52，面板渲染限 30fps。
- 車身訊號（方向燈／倒車／方向盤／雷達）的讀取管道還沒確定，等訊號探測結果。
- `avm_calib.json` 尚未用真實資料校正。
- 正式商用版建議改 NanoDet + NCNN（Apache-2.0）；Ultralytics 權重為 AGPL-3.0。
